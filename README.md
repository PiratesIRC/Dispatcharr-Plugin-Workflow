# Dispatcharr Plugin Workflow

A practical, step-by-step workflow for cleaning up your Dispatcharr lineup after M3U and EPG import using the [PiratesIRC](https://github.com/PiratesIRC) plugin suite.

## 🛠 What it covers

| Step | Plugin | Purpose |
| :---: | --- | --- |
| 1 | IPTV Checker | Probe streams; mark dead and low-framerate sources. |
| 2 | Channel Mapparr | Standardize channel names; sort by category. |
| 3 | Stream Mapparr | Fuzzy-match streams to channels; rank by quality. |
| 4 | EPG Janitor | Find and repair channels with broken EPG. |
| Bonus | Event Channel Managarr | Toggle visibility of event channels. |
