# Screenshots

UI captures used by the guide pages. Reference them from `docs/` like:

```markdown
![Dead channel rename screen](../../screenshots/iptv-checker-rename.png)
```

## Naming convention

`<plugin-slug>-<screen>.png` — for example:

- `iptv-checker-validate.png`
- `channel-mapparr-dry-run.png`
- `stream-mapparr-preview.png`

Keep images under ~500 KB where reasonable. PNG for UI, JPG only if a screenshot includes a photographic element.
