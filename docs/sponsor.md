# Sponsor

[![Sponsor](https://img.shields.io/badge/Sponsor-db61a2?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/PiratesIRC)

The plugins in this guide are free, and so is the guide. That is not going to change.

If they save you time and you would like to support the work, you can sponsor it at [github.com/sponsors/PiratesIRC](https://github.com/sponsors/PiratesIRC).

## What sponsoring does not buy

Being direct about this is worth more than a longer pitch:

- **No priority.** A sponsor's bug report goes in the same queue as everyone else's.
- **No private support channel.** Questions are answered in the open, on the plugin's GitHub issues or on [Discord](https://discord.gg/Sp45V5BcxU), where the next person with the same problem can find the answer.
- **No influence over what gets built.** The roadmap does not change hands.
- **Nothing held back.** No plugin has a paid tier and no capability is gated behind sponsorship.

## Other ways to help, all of them free

These matter, and several of them are how the plugins improved in the first place:

- **Report a bug**, on the repository for the plugin in question. The [Plugin Links](reference/plugin-links.md) page lists all of them. A report that names the plugin version, what you expected and what happened is worth a great deal.
- **Fix something in this guide.** It is a public repository and it goes out of date whenever a plugin ships. See [Contributing](contributing.md).
- **Contribute a lineup.** Lineuparr reads any `*_lineup.json` file you drop in, so a lineup for a provider it does not yet cover is a contribution the whole project keeps.
- **Star the repositories.** It costs nothing and it is how other Dispatcharr users find the plugins.
